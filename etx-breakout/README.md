# etx-breakout

Arcade Breakout game for EdgeTX/OpenTX.

## Controls

- Aileron stick (left/right): move paddle
- Touch slide: move paddle
- Touch tap or TELEM: launch ball
- MODEL: pause/resume
- SYS: start/restart

## Build

- `npm i`
- `npm run build`

Packaged runtime files:

- `_site/breakout.lua`
- `_site/SCRIPTS/Breakout.lua`
- `_site/IMAGES/`
