# etx-racer

Arcade lane racer for EdgeTX/OpenTX, inspired by QQ Speed style gameplay.

## Controls

- Left/Right: switch lanes
- TELEM: nitro boost
- MODEL: pause/resume
- SYS: start/restart

## Build

- `npm i`
- `npm run build`

Packaged outputs:

- `_site/SCRIPTS/TOOLS/Racer.lua`
- `_site/WIDGETS/Racer/main.lua`
