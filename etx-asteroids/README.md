# etx-asteroids

Arcade Asteroids for EdgeTX/OpenTX.

## Controls

- Aileron stick: rotate ship
- Elevator stick up: thrust
- TELEM or Enter: shoot
- Touch left/right: rotate
- Touch center: thrust
- Touch tap: shoot (and start from title)
- MODEL: pause/resume
- SYS: start/restart

## Build

- `npm i`
- `npm run build`

Packaged runtime files:

- `_site/asteroids.lua`
- `_site/SCRIPTS/Asteroids.lua`
- `_site/IMAGES/`
