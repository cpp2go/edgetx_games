# etx-link

Simplified tile-matching game (LianLianKan style) for EdgeTX/OpenTX.

## Controls

- Left/Right: move cursor
- Up/Down: move cursor
- Enter: flip/select tile
- SYS: restart game

## Build

- `npm i`
- `npm run build`

Packaged runtime files:

- `_site/SCRIPTS/TOOLS/Link.lua`
- `_site/WIDGETS/Link/main.lua`
