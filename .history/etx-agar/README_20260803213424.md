# etx-agar

Simplified agar.io-like game for EdgeTX/OpenTX (blob eats blob).

## Controls

- AIL/ELE sticks: move player blob
- SYS: start/restart
- MODEL: pause/resume

## Build

- `npm i`
- `npm run build`

Package outputs into EdgeTX SD structure:

- `_site/WIDGETS/Agar/main.lua` (startup lua)
- `_site/WIDGETS/Agar/Agar.lua` (game logic)
