# etx-agar

Simplified agar.io-like game for EdgeTX/OpenTX (blob eats blob).

## Controls

- AIL/ELE sticks: move player blob
- SYS: start/restart
- MODEL: pause/resume

## Build

- `npm i`
- `npm run build`

Package outputs into EdgeTX SD structure:

- `_site/agar.lua` (startup lua)
- `_site/SCRIPTS/Agar.lua` (game logic)
- `_site/IMAGES/` (image resources)
