# etx-snake

A simple Snake game for EdgeTX/OpenTX, scaffolded like `etx-tetris`.

## Build

- Install dependencies: `npm i`
- Compile Lua: `npm run build`
- Package for SD card layout: `make lua` (or run equivalent copy commands on Windows)

## Output

After packaging, runtime files are:

- `_site/main.lua`
- `_site/ARAR/Snake.lua`
